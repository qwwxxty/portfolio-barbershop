# Гострий кут — сайт-візитка барбершопу

Демо-проєкт для портфоліо: односторінковий сайт вигаданого барбершопу в Сумах.
Бренд, майстри, адреса, контакти й ціни вигадані.

Чистий HTML, CSS і JavaScript без збірки й залежностей — працює на GitHub Pages як є.

## Структура

```
index.html   — розмітка всіх розділів
styles.css   — стилі (mobile-first, брейкпоінти 720px і 1040px)
script.js    — меню, статус «відчинено/зачинено», активний пункт меню, поява блоків
.nojekyll    — щоб GitHub Pages віддавав файли без обробки Jekyll
```

## Як замінити заглушки на фото

Кожна заглушка — це блок `<div class="ph" data-label="...">`. Покладіть усередину зображення:

```html
<div class="ph ph--portrait" data-label="Фото майстра · 4:5">
  <img src="img/master-1.jpg" alt="Олексій Бондар" loading="lazy">
</div>
```

Фото саме заповнить рамку (`object-fit: cover`), підпис заглушки сховається.
Рекомендовані пропорції: перший екран і майстри — 4:5, галерея — будь-які (кадрується).
